# HIVE prototype-1.0 — runtime dependencies
# Deliberately PyTorch-free. The whole ML stack runs on CTranslate2 + ONNX Runtime,
# which saves ~3GB of install and roughly 4 seconds of cold import time.
#
# !! READ THIS BEFORE EDITING !!
# Two dependency hazards on this stack, both of which produce a working-looking
# install that fails only at inference time. install.sh handles both; if you ever
# install by hand, reproduce its ordering.
#
#   1. kokoro-onnx depends on `onnxruntime` (CPU). Installed alongside
#      `onnxruntime-gpu` it unpacks into the SAME onnxruntime/ directory and the
#      CPU core library wins, so CUDAExecutionProvider silently disappears.
#      Fix: install kokoro-onnx first, then force onnxruntime-gpu in last.
#
#   2. Do NOT pin nvidia-cudnn-cu12. onnxruntime-gpu 1.28 is built against CUDA 13
#      and pulls nvidia-cudnn-cu13. Both packages write libcudnn*.so.9 into the
#      same nvidia/cudnn/lib directory, producing a half-9.24 half-9.20 file set
#      and CUDNN_STATUS_SUBLIBRARY_VERSION_MISMATCH on the first ConvTranspose.
#      cu13 alone serves both ORT and CTranslate2 — verified on this box.
